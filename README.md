# jubilant-system

Sabrina's Fight is a tiny browser battle game built as a quick project starter for this repo.

## Run locally

```bash
cd /workspaces/jubilant-system
python3 -m http.server 3000
```

Then open http://localhost:3000 in a browser.

## Controls

- Attack: basic melee damage
- Block: raises focus and defends
- Heal: restores health
- Special: spends focus for a heavy hit

## Files

- `index.html` - arena layout
- `styles.css` - visual styling
- `script.js` - game logic
